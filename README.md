# Kanu Priya Portfolio

Modern single-page portfolio with Apple-style visual feel, smooth reveals, glass cards, and responsive layout.

## Run locally

Open `index.html` directly in browser, or run a local server:

```bash
cd /Users/mac/Desktop/portfolio
python3 -m http.server 5500
```

Then visit `http://localhost:5500`.

## Replace your photo

- Replace `assets/profile-photo.svg` with your real photo.
- Keep the same file name, or update the path in `styles.css` in `.photo-placeholder`.

## Replace company logos with official logos

Replace files inside `assets/company-logos/`:

- `gofloww.svg`
- `rdi.svg`
- `annada.svg`
- `experiaendxe.svg`
- `iide.svg`
- `sundaze.svg`
- `pinkmatter.svg`
- `royal.svg`
- `nooky.svg`

Use SVG or PNG and keep filenames same for instant update.

## Customize links

Update contact links in `index.html`:

- Phone number and email in hero/contact section
- LinkedIn URL in contact section
